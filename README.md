## Radoslaw Brus

Security engineer in Switzerland. I build tooling for securing AI systems — from
the cloud they run on to the agents running on it.

I started in cloud security, building vulnerability scanners for Azure and AWS. As
agents and LLM-powered systems began shipping into production, the interesting
attack surface moved with them, and so did I. Most of my recent work is red-teaming
autonomous agents and the infrastructure around them.

### Focus

- **AI / LLM security** — red-teaming agents, prompt-injection and tool-abuse, evidence that stands up to an auditor
- **Zero-Trust and cloud architecture** — Azure, GCP, AWS; identity, network, and data-residency boundaries
- **Edge and IoT** — running models and security workloads on constrained hardware (Jetson, DGX)

### Selected work

- **[redwire](https://github.com/rbrus/redwire)** — reach an AI agent over REST, MCP, A2A, WebSocket, or a browser chat widget through one Go interface. SSRF-guarded by default, standard library first, 85 behavioural tests.
- **Sixi AI** ([sixi-ai](https://github.com/sixi-ai)) — an enterprise agentic-AI red-teaming platform mapping findings to the EU AI Act and GDPR. Swiss-domiciled, sovereignty-first.
- **[GlassBox Edge](https://github.com/rbrus/GlassBoxEdge)** — an AI assistant grounded in live OT telemetry, running on edge nodes, built to be attacked.
